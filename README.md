# Project Overview

# FPSO Kwanza Star - 2027 Major Planned Shutdown (Turnaround)
# PROJECT SNAPSHOT
Project ID: KWZ-SD27
Asset: FPSO Kwanza Star (fictional), offshore Angola. Spread-moored turret FPSO, topsides process trains, 3 gas turbine generators.
Planned project start: 04-Jan-2027 (Monday). Shutdown window start: 17-May-2027. First oil: 21-Jun-2027. Project closed: 09-Jul-2027.
Shutdown duration (Production Stopped to First Oil): 33 calendar days. Full window (Shutdown Start to Restart Complete): 39 calendar days.
Structure: 12 WBS groups, 60 work packages (WBS lines), 273 activities (3 to 7 per work package).

# ASSUMPTIONS
1. Currency USD. Labour rates are blended, fully burdened hourly rates (wage, offshore allowances, overheads, margin).
2. Labour units are hours = crew size x shift hours x activity duration. Offshore shift is 12h, onshore 8h. Crew size is per shift.
3. Non-labour units are days = quantity per day x activity duration. Materials are modelled as a consumption lot per day of use so every non-labour price is per day, as requested.
4. Marine spread items (PSV, flotel, helicopter, ROV) are daily charter rates. Their cost accrues across Level of Effort (LOE) activities, which stretch from one milestone to another.
5. Dates in Activities are a forward pass only (no float). Load the file in P6 to get float, critical path and resource profiles.
6. Onshore holidays used: 04-Feb, 09-Feb, 08-Mar, 26-Mar 2027. Offshore works every day.
7. Rates and durations are plausible planning figures for a simulation, not benchmark data from a real contract.
